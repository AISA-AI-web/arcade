Code Your Own Class Activities

Ask Gemini Canvas to code an interactive game or quiz as one HTML file. Then paste it into the AISA Activity Hub to get a link, a QR code and a Google Classroom button. No coding knowledge needed. The demo is a Grade 10 English game called Ethos, Pathos or Logos?

2 tools Gemini Canvas, AISA Activity Hub~20 min from idea to linkOutput A link and QR code that open on any device
Before you start
  1. Open Gemini with your AISA account, and open the AISA Activity Hub in a second tab.
  2. Pick one skill or concept your students need to practise in the next two weeks. Games that sort, match or quiz work best.
  3. Leave student names and personal details out of your prompt. Activities on the Hub can be opened by anyone with the link.

Let the Gem write the prompt for you

  1. Open the EduSim Gem with your AISA account.
  2. Type your grade, subject and topic. It's fine to say you're not sure where to start.
  3. Answer its questions until it builds the activity.
  4. Play it, then copy the code (Part 2) and paste it into the Hub (Part 3).

Open the EduSim Gem ↗
Prompt recipe · change the words in [brackets] Make a single self-contained HTML file: a [sorting game / quiz / matching game / flashcards] for Grade [X] [subject] called "[title]". [Say what students do, one step at a time.] After each answer, explain in one sentence why. Show a score and a Play again button at the end. Clear, simple English for EAL learners, big buttons that work on a laptop, iPad or phone, no external images or links.
  1. 1

    Turn on Canvas

    In Gemini, click the + at the left of the chat box. Click More tools, then Canvas.

    A Canvas chip appears in the chat box, so Gemini knows to build something rather than just reply.

    Can't see Canvas? Make your browser window wider; the menu hides it in a narrow window. Or end your prompt with Build it in Canvas.
  2. Canvas on
    Ask Gemini
    +Canvas
    2

    Describe the activity and send

    Copy the prompt recipe above, paste it into the chat box and change the words in brackets. Then click the send arrow.

    Two phrases do the heavy lifting:

    • "a single self-contained HTML file" puts everything in one file, which is exactly what the Hub needs.
    • "big buttons that work on a laptop, iPad or phone" makes it easy to use on student devices.
    Be specific about content. Say how many questions, the grade, and where your students live. Our prompt asked for examples a teenager in the UAE would hear.
  3. 3

    Meet the Canvas toolbar

    After a minute or two the activity opens in Canvas. Across the top:

    • Code / Preview: switch between the code and the working activity.
    • Download: saves the HTML file to your computer.
    • The share icon: the quickest way to copy the code (Part 2).
    • The full screen icon: hides the chat so you can play it bigger.
  4. 4

    Play it like a student

    Play every question in Preview. Get some wrong on purpose to see the feedback.

    Want a change? Just ask in the chat, for example Make the buttons bigger or Replace question 4 with one about school uniform. Gemini updates the same Canvas.

    Check every answer. Gemini can label a line wrongly or give a weak reason. You are the subject expert.
  5. 5

    Got an error? Ask again

    When lots of people use Gemini at once you may see Sorry, something went wrong or Pro is in high demand. This happened to us during the demo.

    Type Please try again and build it in Canvas. and send. You don't need to paste your prompt again.

Part 2 · Copy the code

Copy the code: two ways

The Hub needs the code, not a Gemini link. Both ways below copy the whole file. Try Option A first; if nothing pastes in Part 3, use Option B.

Option A · Quickest

Copy contents

Click the share icon in the Canvas toolbar, then Copy contents.

Two clicks → Option B · If A doesn't work

Select all in the code

Click Code, click inside the code, press ⌘A then ⌘C.

Works every time →
  1. A

    Option A: Copy contents

    In the Canvas toolbar, click the share icon (three connected dots, next to Download). Click Copy contents.

    Look for Copied to clipboard at the bottom left. The whole file is now copied, so go to Part 3 and paste it.

    Don't click Share. It makes a public Gemini link straight away. The Hub gives you a better link, a QR code and a Classroom button instead.
  2. B

    Option B: Select all, then copy

    Use this if Option A doesn't paste anything.

    1. Click Code in the Canvas toolbar.
    2. Click inside the code box, anywhere in the code.
    3. Press ⌘ Cmd + A to select all of it. The code turns blue.
    4. Press ⌘ Cmd + C to copy.

    Now switch to your Activity Hub tab to paste it (Part 3).

    Click in the code first. If you press ⌘A without clicking in the code box, you select the whole Gemini page instead, chat and all.
Part 3 · AISA Activity Hub

Paste it into the Hub and publish

The Activity Hub turns your code into a web page with its own link. It reads your code, guesses the title, grade and subject, and adds it to a shared library for AISA staff.

Works with code from Gemini, ChatGPT, Claude or CanvaOpen Create ↗
  1. 1

    Open Create

    In the Activity Hub, click Create an activity, or + Create at the top.

    The page has three parts: 1 Paste your code, 2 Check the preview and 3 Describe it for the library.

  2. 2

    Paste your code

    Switch to your Activity Hub tab. Click inside Paste your HTML here and press ⌘V. Or click the Paste button.

    The preview on the right starts running straight away.

    Downloaded the file instead? Click Upload file and choose the .html file. Copied some of Gemini's chat along with the code? That's fine, the Hub tidies it up.
  3. 3

    Check the preview

    Use the icons above the preview to see it at desktop, tablet and phone size. Play a few questions in phone view: that's how it looks when students scan the QR code.

    • ↻ restarts the activity.
    • Full screen and Download are there too.

    Under the code you'll see its size, for example 522 lines · 27 KB. A handful of lines usually means only part of the code was copied, so copy it again.

  4. 4

    Check what the Hub guessed

    Scroll to 3 Describe it for the library. Fields marked AUTO-DETECTED are guesses from your code. In our demo:

    • Activity type said Quiz. We changed it to Game.
    • Grade level(s) only had 10 ticked.
    • Short description was a line of text from inside the game.
    Colleagues search by these details. A clear title, grade and description is what makes your activity findable in the library.
  5. 5

    Fix the details, then publish

    • Grade level(s): click every grade it suits. We added 9 and 11.
    • Short description: say what students do, in one sentence.
    • Tags: words a colleague might search for, separated by commas.
    • Shown as: your name as it appears in the library.

    Click Publish & get link. It takes a few seconds.

Part 4 · Share

Get it to your students

Your activity now has its own page. Students don't need an account: they open the link or scan the QR code.

  1. 1

    Your activity is live

    A box pops up with everything you need:

    • Copy: copies the link, ready to paste anywhere.
    • Share to Google Classroom: posts it to one of your classes.
    • Show QR code full screen: put it on the board for students to scan.
    • Download QR code (PNG): add it to slides or a worksheet.
    • Open activity in a new tab.
  2. 2

    Use the activity page

    Closed the box? The same buttons are along the top of your activity page: Classroom, QR code, Copy link, Download and Full screen.

    Click … for more:

    • Edit: fix a mistake or paste in new code.
    • View code and Details.
    • Delete: take it down.
    Full screen on the board. Play it together as a class first, then let students try it on their own devices.
Part 5 · Library

Find, share and remix colleagues' work

Every published activity goes into the shared library. Before you build something new, check whether a colleague already has.

Open the library ↗
  1. 1

    Search and filter

    Search by topic, title, concept, tag or teacher. Click a grade such as Gr 10, or use the subject, activity type and sort menus.

    My activities shows only yours.

    Each card has Open and quick icons for the QR code, Google Classroom, Download and Remix.

  2. 2

    Remix to make it yours

    Click the Remix icon on a card, or Remix (make my own copy) in the … menu. The code and details load into Create.

    Change them, then publish your own copy with its own link. The original stays as it is.

    Remix with Gemini. Copy the code from the Remix page, paste it into Gemini and ask, for example, Keep the design but change the questions to Grade 7 science: states of matter. Paste the new code back and publish.

Before students use it

Check it

Play every question

Gemini can sort an example into the wrong category or give a weak reason. Check every answer and explanation.

Test on a student device

We asked for no external links, but our game still loaded its styles and font from the internet (look near the top of the code). It needs Wi-Fi, so test it on a student laptop or iPad on the school network.

Keep it free of student data

Anyone with the link can open it and colleagues can see it in the library. No student names, photos or personal details in the code or description.

Know what it doesn't do

Our game shows a score on screen but doesn't send results to you. If you need evidence, ask students to screenshot their score or follow it with a Google Form.
